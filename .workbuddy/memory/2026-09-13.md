### 三个必须记住的坑
1. **这个定制 chessboard 的 `position(fen)` 默认走"动画"路径**：把 `moveSpeed/appearSpeed` 归零会
   导致**棋盘完全不动**（走法记录在变、DOM 不变）。必须显式 `board.position(fen, false)` 落位，
   再由 FLIP 做动画。
2. **棋子是格子的子元素且每次走子被重建**（position:static、无 left/top）→ FLIP 不能用元素同一性匹配，
   必须按「格子 + 棋子类型」找来源（同类棋子中"旧格子已不在新局面上"且距离最近者）。
3. **棋盘每手晃动的根因**：`#evalpct`（"白 50.0%"）文字宽度变化 → `.eval-col` 宽度 44↔57px
   → `.board-zone` 整条 flex 重新居中 → **棋盘横向平移 ±7px**。修法：`.eval-col{flex:0 0 64px}`
   + `#evalpct{width:100%;text-align:center;font-variant-numeric:tabular-nums}`。
- 验证手法（可复用）：MutationObserver 捕获 `.piece-reposition` 出现 → 每 16ms 采样该棋子 rect
  直到 class 移除 → 得到时长与曲线形状；对照 Kylin 采样曲线（同为强缓出递减）。
- 版本：chess-motion.js?v=4、chess-motion.css?v=1、chess.js?v=47。

## 补课：Kylin 走子动效其实是「三件套」（已上线）

上一轮我只扒到 `_boardPieceReposition`（局面重排：.46s 带模糊+72%绿光），**漏了走子专用的那套**。
完整三件套（StudyChessBoard chunk 内逐字定义）：
1. **走子位移 `_arcadePieceMotion`**：`.22s cubic-bezier(.2,.82,.24,1)`，
   `translate3d(var(--piece-dx),var(--piece-dy),0)`，opacity .72→1；位移量用**百分比**（相对自身尺寸）。
2. **轨迹残影 `_moveTrace` + `@keyframes _arcadeTrace`**（用户说的"尾部残留动画"）：
   `.44s cubic-bezier(.16,1,.3,1)`，stroke #d7ff3f / 7px / dasharray 19 12 / drop-shadow(0 0 4px #d7ff3fb8)；
   `0%{opacity:0; stroke-dashoffset:80px} 18%{opacity:.95} 100%{opacity:0; stroke-dashoffset:0}`
   → 棋子在 .22s 到位后，绿虚线继续流动并淡出到 .44s。
3. **最后一手残留 `_lastMoveSquare`**：起止格 `linear-gradient(#d7ff3f29,#d7ff3f29)` 淡绿底，保留到下一手。
分流规则：单子移动（走子/悔棋）→ ①；多子重排（易位/载入）→ `_boardPieceReposition`（带错峰）。
实现位置：`css/chess-motion.css`（v2）+ `js/chess-motion.js`（v5，新增 `.star-trace-layer` SVG 叠加层
与 pulse() 的残留替换）。
⚠️ **教训**：扒别人动效时不要只找"名字最像"的那条规则，要把该组件 chunk 里**所有**相关类名/关键帧
一次性列全（这次是靠类名清单里冒出 `_arcadePieceMotion` / `_moveTrace` / `_lastMoveSquare` 才补全）。
