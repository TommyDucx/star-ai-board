## 棋子移动动效：完全对齐 Project Kylin（已上线）

- **Kylin 的实现（扒其 StudyChessBoard chunk + 逐帧实测）**：
  `animation: _boardPieceReposition .46s var(--reposition-delay,0s) cubic-bezier(.16,1,.3,1) both`，
  关键帧 `0%{opacity:.22; transform:translate(var(--x),var(--y)); filter:blur(1px)} →
  72%{opacity:1; transform:translate(0); filter:drop-shadow(0 0 7px #d7ff3f33)} → 100%{filter:none}`；
  棋子浮在独立层 `_boardPiece`（z-index:3, will-change:transform,opacity），支持多子错峰。
  实测其位移是连续插值（每 16ms 递减），非瞬移。
- **本站改造**：`js/chess-motion.js` 重写为 FLIP（记录旧坐标 → 瞬时落位 → 给位移过的棋子注入
  `--rp-x/--rp-y/--rp-delay` 并播放同款关键帧），新增 `css/chess-motion.css`（参数逐字对齐 Kylin）。
  引擎应手/悔棋走动画；新局瞬时（交给既有 `.piece-assemble` 入场，避免两个动画打架）。

### 三个必须记住的坑
1. **这个定制 chessboard 的 `position(fen)` 默认走"动画"路径**：把 `moveSpeed/appearSpeed` 归零会
   导致**棋盘完全不动**（走法记录在变、DOM 不变）。必须显式 `board.position(fen, false)` 落位，
   再由 FLIP 做动画。
2. **棋子是格子的子元素且每次走子被重建**（position:static、无 left/top）→ FLIP 不能用元素同一性匹配，
   必须按「格子 + 棋子类型」找来源（同类棋子中"旧格子已不在新局面上"且距离最近者）。
3. **棋盘每手晃动的根因**：`#evalpct`（"白 50.0%"）文字宽度变化 → `.eval-col` 宽度 44↔57px
   → `.board-zone` 整条 flex 重新居中 → **棋盘横向平移 ±7px**。修法：`.eval-col{flex:0 0 64px}`
   + `#evalpct{width:100%;text-align:center;font-variant-numeric:tabular-nums}`。
- 验证手法（可复用）：MutationObserver 捕获 `.piece-reposition` 出现 → 每 16ms 采样该棋子 rect
  直到 class 移除 → 得到时长与曲线形状；对照 Kylin 采样曲线（同为强缓出递减）。
