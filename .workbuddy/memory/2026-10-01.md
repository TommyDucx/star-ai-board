## 棋子动效全站覆盖核查（三件套）+ CDN 缓存坑

- **核查结论：7 个国际象棋界面全部到位**（线上域名实测，含街机位移 / 彗星拖尾 / 落点残留高亮）：
  引擎对战 chess.html、棋力评估 assessment.html、棋谱库演示器、背谱训练、战术闯关 tactics.html、
  复盘回放 review.html、首页演示棋盘 index.html。
- 本轮补的两处缺口：**复盘回放**与**首页演示棋盘**原来只调了 `sync`（只有位移），已补 `pulse`
  （拖尾 + 残留高亮）。
- 新增：拖尾线宽按格子边长自适应（`--trace-w = clamp(3, 格子/11, 8)px`）——Kylin 的 7px 对应 ~600px 棋盘，
  首页演示盘只有 31px 格子，写死 7px 会显得极粗。实测：主棋盘 7.2px、战术 6.7px、演示盘 3.0px、复盘 3.4px。
- ⚠️ **CDN 缓存坑（重要）**：Cloudflare 对 `/js/*`、`/css/*` 按
  `cache-control: public, max-age=31536000, immutable` **在边缘缓存一年**。因此
  **改 JS/CSS 必须同时升 `?v=` 版本号**，否则线上仍发旧文件（本次 `intro.js` 忘了升版本，
  导致首页演示盘刷不到新代码；树莓派本地文件其实已是新版，带随机 query 请求就能看到）。
  排查手法：`curl -sI .../js/x.js | grep -E 'cf-cache-status|age|cache-control'`，
  再用 `curl '.../js/x.js?nocache=<ts>'` 对比内容确认是不是缓存问题。
- 覆盖审计手法（可复用）：探针用**轮询**而非 MutationObserver（后者只监听 class 变化，
  会漏掉 SVG 轨迹的 childList 变化，导致误判"没有拖尾"）；复盘页**需要登录**才能分析，
  匿名访问会显示"复盘失败: 未登录"。
- 核查产生的测试数据已全部清理：2 个临时账号（账号 3→1，仅剩 `Tommy`）、各 1 条"QA 动效核查线路"
  训练计划、2 条同名棋谱条目（库恢复为 5 条正式棋谱）；accounts.json / trainer.json 均有 `.bak-*` 备份，
  校验无 null 损坏，临时账号登录返回 401，两个服务 active。
