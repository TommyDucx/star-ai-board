# 2026-09-19

## 路由切换特效体系（8 种语汇）+ 首页纹章放大（已上线）

- **参考 Kylin 的过渡语言**（重新抓其 chunk 得到确切参数）：统一曲线 `cubic-bezier(.76,0,.24,1)`，
  桥牌 `_libraryEntryBridge` `.42s`（网格 84px 面板 → `clip-path: inset(0 0 72%)` 向上擦除），
  目录幕布 `_studyDirectoryTransition` `.62s`（`clip-path: inset(0 0 100%)` → 0 自下揭开，
  底部 70px 内边距放目的地标签），元素级 resolve 关键帧各页不同
  （header `translateY(-70px)`、rail `clip-path inset(0 0 100%)+translateX(-34px)`、
  rows `translateY(36px)`、intro `translate(8vw,-22px)`）。
- **我的实现**：`js/motion.js` 的 `flowOf(from,to)` 按来源→目标分配 8 种（bridge/curtain/wipeX/
  radial/chessGrid/diagonal/flipUp/zoomOut），`sliceRoute(href,{type,point})` 生成 `.route-veil`
  幕布（带目的地中文名 + mono 标签 + 进度条；chessGrid 为 64 个 12.5% 方块错峰）；
  `enterFlow()` 按 `PAGE_META[to].enter` 给目标页元素挂 enter-* 编队类（来源页记在
  `sessionStorage.star_from`，直接打开不编队）。
- **流畅性**：过渡期间 `<html>.route-busy` 暂停扫描线/像素故障/极光/光标拖尾的常驻动画；
  幕布只动 clip-path/transform/opacity + `contain:strict`。实测幕布期间帧中位 16.5–16.8ms、
  最长 17.5–35.5ms、无持续卡顿。
- **首页纹章（猫 `.lynx-sigil`）放大**：210–340px、opacity .96、光晕加强；窄屏 168/132px。
  实测 1440 → 300×300，1024 → 213，390 → 131。
- ⚠️ 验证方法备忘：想抓「幕布完全覆盖」那一帧，用 `setRequestInterception` 拦后续导航
  （注意：必须在首次 goto 之后再开启拦截，否则首屏也被拦掉）；读不到幕布数据时，
  改用「跳转前把探针写入 sessionStorage、跳转后读回」——比拦截可靠。
- 版本：motion.js v37 / motion.css v39（全站 8 页升位）。
