## 文学作品权限（登录 + 仅作者可读）+ 申请授权 + 首页通知栏 + 按钮统一圆角

### 权限模型
- **受保护作品**（作者=杜承轩 → 文章 key `bach`/`jasmine`）：正文**移出页面**，只存
  `admin/literature_content.json`（不入公开仓库，见下）；`GET /api/literature/:key/text`
  内部判权，未获授权一律 403（state: need_login / none / pending / denied），
  获权（owner/approved）才返回 paragraphs。**评论同样要求授权**。
- 作者（owner = `Tommy`，写在内容文件里）可直接查看；其他账号走申请：
  `POST /api/literature/:key/access/request` → 作者在通知栏
  `POST /api/literature/:key/access/decide {userId, approve}`（非作者调用返回「只有作者本人可以审批」）。
- `GET /api/notifications`：作者视角 `pending[]`（待审批列表），读者视角 `mine[]`（我的申请状态）。
- ⚠️ 坑 1：`handleApi` 的「以下均需要登录」网关会拦掉写在其后的接口 → **GET 正文放网关前**
  （内部自行判权），申请/审批/通知放网关后。
- ⚠️ 坑 2：`litPublic` 原先只列出「已有互动记录」的文章 → 受保护但零互动的文章不会出现在列表里、
  前端拿不到 gated 状态；已改为「并集合内容文件的 key」，且对没有记录的文章用空壳（计数 0）返回。

### 前端
- 个人主页 `/me/`：卡片加锁标识（需授权/待审批/已授权/作者），阅读抽屉按权限渲染
  ——有权限拉正文+留言区，无权限显示锁定面板（登录引导 / 申请查看 / 待审批 / 重新申请）。
- 站点首页顶栏加**通知铃铛**（含角标，60s 轮询）：作者看到待审批列表与「同意/拒绝」，
  读者看到自己的申请状态；样式与站点工业风一致。
- **按钮统一圆角**：`css/site.css` 加 `--btn-radius: 999px` + 按钮族统一规则（胶囊形），
  与个人主页既有的 99px 圆角一致；改形状只需改这一个变量。
